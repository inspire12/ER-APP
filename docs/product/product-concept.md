# 응급실 스마트 퇴원 안내 서비스 전체 구상

- 문서 버전: 0.1
- 작성일: 2026-09-06
- 상태: 제품 비전

## 1. 서비스 목표

응급실 의료진이 퇴원 설명을 빠르고 일관되게 작성하고, 환자가 귀가 후에도 모바일 웹에서 복약·생활 안내와 재내원 기준을 쉽게 확인할 수 있도록 한다.

## 2. 전체 사용자 여정

### 1단계: 의료진 입력과 안내문 발급

1. 의료진이 마이크 또는 텍스트로 진료 내용을 입력한다.
2. STT가 음성을 텍스트로 변환한다.
3. AI가 진단명, 검사·진찰 소견, 처방 내용과 템플릿 검색어를 구조화한다.
4. 시스템이 DB에 저장된 검수 안내문을 추천한다.
5. 의료진이 환자별 내용과 안내 문구를 직접 수정·확인한다.
6. 의료진이 최종 승인한다.
7. 환자용 웹 링크와 QR 코드를 발급한다.

AI는 새로운 의료 안내를 자유롭게 생성하지 않는다. 병원에서 검수해 DB에 저장한 콘텐츠를 선택하고, 의료진의 입력을 정리하는 역할로 제한한다.

### 2단계: 환자용 모바일 웹

환자는 별도 앱 설치 없이 링크 또는 QR로 모바일 웹에 접속한다.

환자 화면에서 제공할 정보:

- 진단명 또는 의심 질환
- 검사 및 진찰 소견
- 처방약과 처방 이유
- 복약 방법
- 식이·활동·자가관리 안내
- 예상 회복 과정
- 즉시 재내원해야 하는 위험 신호
- 추적 외래 안내

### 3단계: 귀가 후 지원

#### 복약 알림

- 환자가 복용 시간을 직접 설정한다.
- 웹 푸시 또는 카카오 알림톡으로 복약 시간을 알린다.
- 안내된 처방 횟수와 복용 조건을 벗어난 알림은 생성하지 않는다.

#### 제한형 AI Q&A

- 병원 검수 퇴원 가이드와 승인된 지침만 검색 대상으로 사용한다.
- 발급된 환자 안내문을 질문의 기본 문맥으로 사용한다.
- 새로운 진단, 약물 추가·중단, 용량 변경을 지시하지 않는다.
- 근거가 없거나 불확실하면 답변하지 않고 의료진 확인을 안내한다.
- 위험 증상이 포함된 질문에는 챗봇 답변보다 재내원 안내를 우선한다.
- 자주 묻는 질문을 상단 버튼으로 제공한다.

FAQ 예시:

- 먹어도 되는 음식
- 피해야 하는 음식
- 약 복용 방법
- 예상 회복 기간
- 병원에 다시 와야 하는 증상

#### 상태 피드백

- `많이 좋아졌어요` 버튼을 누르면 회복 및 추적 외래 안내를 제공한다.
- `증상이 심해졌어요` 버튼을 누르면 위험 신호와 재내원 기준을 먼저 표시한다.
- 의료진 알림은 병원에서 실제 모니터링 담당자와 대응 절차가 정해진 후 활성화한다.
- 의료진이 즉시 확인한다는 표현은 대응 체계가 없는 상태에서 사용하지 않는다.

## 3. 단계별 개발 범위

### MVP 1: 안내문 생성과 전달

- 텍스트 입력과 기기 기본 받아쓰기
- AI 기반 진료정보 구조화 및 DB 템플릿 추천
- 질환별 안내 콘텐츠 DB 관리
- 의료진 수정·확인·승인
- 모바일 환자 안내문
- 환자 링크 및 QR 동시 발급
- 데모 모드

### MVP 2: 음성 입력과 환자 편의

- 앱 내부 마이크 녹음
- STT 자동 변환
- 환자용 FAQ 바로가기
- `호전됨 / 악화됨` 상태 입력 및 기록
- 웹 앱 홈 화면 추가 지원

### 확장 단계

- 검수 지식 기반 제한형 AI Q&A
- 복약 시간 설정 및 웹 푸시
- 카카오 알림톡 연동
- 의료진 경과 대시보드
- 악화 알림과 담당자 대응 워크플로
- EMR 및 처방정보 연동

## 4. 핵심 안전 원칙

- 모든 환자 안내문은 의료진 승인 후 공개한다.
- AI가 입력에 없는 진단·검사·약물 정보를 만들지 않는다.
- 복약 정보는 처방 데이터 또는 의료진 입력만 사용한다.
- 악화 알림은 기록만 하는 기능과 의료진이 실제 대응하는 기능을 구분한다.
- 환자에게 응답 시간을 보장하지 않는 기능을 실시간 상담처럼 표시하지 않는다.
- QR에는 환자 정보가 아닌 임의의 접근 토큰만 포함한다.
